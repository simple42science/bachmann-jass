# Kartenbilder

36 Karten des Schweizer Blatts als WebP, 720 Pixel breit, erzeugt mit `tool/convert_cards.py` aus dem Kartenset `jasskarten_deck_png_sharper` der bisherigen Web-App.

Dateiname: `<farbe>_<rang>.webp`, zum Beispiel `rosen_under.webp`. Farben: eicheln, rosen, schellen, schilten. Raenge: 6, 7, 8, 9, 10, under, ober, koenig, ass.

Herkunft und Lizenz: laut Besitzer Open Source (Entscheid D6). Quelle und Lizenztext sind hier noch nachzutragen, bevor die App in einen Store kommt.
